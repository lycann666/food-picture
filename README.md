A steaming bowl of tonkotsu ramen on a dark walnut table — chopsticks lifting a glossy bundle of noodles from a golden broth, a jammy egg, rolled chashu, nori, green onions and chilli oil, steam curling into warm light. Drawn entirely in code, pure Python standard library, no image files.

## Run it

```sh
python3 main.py
```

Writes one deterministic 512×512 PNG to `/output/entry.png` (override the output directory with `MAKEFUN_OUTPUT_DIR`). Runs in about 8 seconds, standard library only, no network. Running it twice produces byte-identical output.
